# Sistema de Cadastro de Alunos

## Objetivo
Criar um sistema simples para cadastro e consulta de alunos.

## Tecnologias
- PHP: Faz o site funcionar por trás das câmeras.
- HTML: Cria a Estrutura da página.
- Git: Salva o histórico do código no seu computador.
- GitHub: Guarda o projeto na internet.
Alguns Comandos: 
-Push: Envia seu código para o GitHub.
-Pull: Baixa o código do GitHub para a sua máquina.
